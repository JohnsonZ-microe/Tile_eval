# Predicted D commits through continuous Y output

Inputs: external raw CTRL DRAIN records and conditional D commits generated by the sibling d-commit-inputs audit. Trace digest is checked against that prediction artifact before reuse. Observed Y outputs are used only for comparison after prediction.

Both received runs passed: 600 Y output edges and complete sidebands, 60 visible Y-ready slot edges and 60 registered DRAIN edges/fields match exactly. All valid slots are consumed by the end. Complete sideband comparison includes tag/bank/slot, segment and packet last; numeric payload is not checked.

Credit assumption is explicit: one persistent Y-only bus starts with six credits and returns one credit on the edge following every predicted beat. This is generated feedback, not the actual external credit trace and not an observed-output seed. H and STATUS are absent. Upstream commit prediction retains isolated-phase assumptions. Thus this evidence does not establish full-Tile output arbitration, sustained throughput, numerical correctness or arbitrary repeated-slot accumulation. It does connect raw commands and predicted commit timing through finite Y control to complete Y packet identity/timing.

Reproduce d-commit-inputs/check.py first, then this directory's check.py. Both audit scripts and checks.json retain expected and actual arrays; sources.json binds current model files. Original manifests and traces were not modified.
